How to reproduce the experiment

Save this JSON together with the project commit SHA, SUMO version, controller parameters and result files. The current experiment runner accepts the scenario, controller, seed, demand scale, preemption setting and optional end time. A future sandbox execution service will run these configurations; this static page only creates them.




What each setting means
Scenario: the network demand and timed events. Controller: the traffic-light decision rule. Seed: reproducible random traffic. Demand multiplier: scale the existing vehicle flows. Preemption: emergency-vehicle signal priority. Duration: optional experiment end time.
